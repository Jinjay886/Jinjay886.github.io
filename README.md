# Jin Haoyu's Personal GitHub Page
Personal homepage built with Jekyll, deployed on GitHub Pages.

## Deployment Steps
1. Create a new GitHub repository named `jinhaoyu.github.io` (replace `jinhaoyu` with your GitHub username)
2. Clone this repository to your local machine
3. Push all files to the repository
4. Enable GitHub Pages in repository settings (Settings > Pages > Source: main branch)
5. Visit `https://jinhaoyu.github.io` to see your homepage

## Customization
- Modify `_config.yml` to update personal information (email, GitHub username, etc.)
- Edit `index.html` to add/remove sections (e.g., honors, hobbies)
- Adjust `assets/css/style.css` to change colors, fonts, or layout
